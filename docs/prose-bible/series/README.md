# Series Studies

Twenty cards, one per series, in rank order. Every card uses the same fixed headings so that voices can be
compared without metaphor:

1. Card (dates, corpus, POV/tense, setting)
2. Read first
3. Popularity evidence
4. Voice card (dials)
5. What the series solved
6. Syntax and prose mechanics
7. Character psychology
8. Signature devices
9. What to steal / what to avoid
10. Diagnostic passage (original, annotated)
11. Exercise

## How to read a card

- **Start with "What the series solved."** It tells you what the series is *for*; the rest is technique.
- **Read the syntax section with a pencil.** Mark the sentence lengths in the diagnostic passage; check the
  dial values against your own reading.
- **Do the exercise before you read the annotation again.** The point is to feel the constraint, not to
  admire the analysis.
- **Treat "Avoid" as seriously as "Steal."** The failure modes are usually the same devices taken one step
  too far.

## A note on the diagnostic passages

All diagnostic passages are **original prose written for this project**, not quotations from the novels.
They are pastiche in the technical sense: writing under a voice's constraints. They exist to show the
mechanism, not to substitute for the source.

See [`../05-voice-recipes.md`](../05-voice-recipes.md) for the modular version of these recipes and
[`../08-sources-and-glossary.md`](../08-sources-and-glossary.md) for the evidence base.
